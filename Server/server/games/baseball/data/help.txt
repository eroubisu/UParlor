## welcome 棒球
◆ 棒球 (1v1)

  1v1 对决（局数创建房间时选，默认 3 局）：守方选球路，攻方猜球路。
  双方同时出牌，倒数后开投，球到了自己按「击球」。
  追球、接球、传球、跑垒全程实时操作。

## rules 规则

  ◆ 比赛流程
    局数由房主创建房间时选（1–9 局，默认 3 局）；每局上下半各 3 个出局；
    开局随机定先后攻（客队先攻）。
    4 个坏球保送，3 个好球三振；界外球不会让你被三振。
    末局上半结束时主队已经领先，下半局不再进行；
    末局下半主队一取得领先，比赛立刻结束（再见分）；打平算平局，不加赛。
    比分、出局数、球数在右上角状态面板（局面页），逐局得分在「比分」页。
    上方的记录栏默认显示最新的一条：移到这一栏（shift+↑）后按 ↑ ↓ 逐条回看，
    回看时新记录不会把你拽走，焦点离开又回到最新一条；完整内容也在「记录」窗口里。
    记录里的计数写成 `1-2`（坏球-好球），比分 `A 4-2 B`（客队在前）。

  ◆ 操作
    所有操作都在棋盘下方的操作区：← → ↑ ↓ 移动光标（h / l 与 ← / → 等效），回车执行。
    设置菜单：回车进入二级菜单选值，选完自动回到一级；最后一项「确定」→「是」才交出去。
    按钮盘（追球、跑垒）：光标落到哪个按钮，哪个就立刻生效，不用回车；追球时回车是起跳。
    传球不能撤销，所以要回车确认。
    暂时不能按的菜单会先摆出来当预告，可以先把光标摆好。

  ◆ 一球的流程
    1. 双方同时出牌：
       守方设置 布阵 / 球种 / 区域 / 力度（垒上有人时多一项「跑者」）；
       打者设置 预判 / 挥棒（垒上有人时多一项「盗垒」）。
       设置留在本地，选「确定」→「是」那一刻才交出，交过就不能再改。
       上一球的设置会保留，交过一次牌之后光标直接停在「确定」，原样再来一球回车两下。
    2. 双方都交牌后倒数 3→2→1（显示在投打行右端）。
    3. 倒数完投手按「投球」把球投出去。打者的「击球」键交牌后就在，球投出去才能按。
    4. 球从投手飞向本垒约 1.3 秒，球到后还有约 0.4 秒的挥棒段。
       打者按「击球」就是挥棒；不按就是放过去，按好坏球判定。
    5. 动画最后一帧揭晓结果，记录栏里是一行：这一球的结果、计数，
       以及「时机提前 预判正确」这样的事实，供下一球参考。

  ◆ 守方：投球
    布阵：标准站位 / 偏左外野 / 偏右外野 / 内野前压 / 外野退守，选中立刻生效。
    球种：四缝线速球 / 卡特球 / 滑球 / 变速球 / 指叉球，球速、变化、控球风险
      与体力消耗各不相同，打者要用的击球时机也不同。
    区域：好球带内 / 好球带边缘 / 坏球区。力度：标准 / 全力。
      全力球速更快，但更容易失投、更费体力，打者要再早一档按。
    跑者：垒上有人时才有这一项。「牵制跑者」让盗垒成功率大幅下降，
      代价是投手分心、打者更容易打到球；垒上没人时没有对象，不显示。
    侦察页记着最近三球，可以据此判断对手的习惯。

  ◆ 攻方：打击
    预判：猜这一球的球种，猜对更容易打到。
    挥棒：标准挥击（较稳）/ 大力挥击（更易长打，更容易挥空）/ 滚地球（一定是滚地，
      不会长打；三垒有人时有机会换分）。
    击球时机由你按下去的那一刻决定，不是菜单选项：
      投打行上有两条淡色分界线，把球路分成 提前 / 正常 / 延后 三档，
      球越过线就换档。球一按下，本垒处亮起实心标记（对手也看得到）。
      快球要早按，变速球要晚按；球到了本垒还没按，再按就是「延后」。
    时机或预判不对不一定挥空，也可能是界外或打成弱球。
    盗垒：垒上有人时才有这一项，「领跑者盗垒 / 保持 / 全体盗垒」，随打击一起交出；
      起跑的人在投球动画里跑，球出结果时判定成败，成功率看跑者速度。

  ◆ 击出之后
    球被打出去后沿外野线飞行（共 12 格），最右侧的实心区是本垒打墙；
      击球质量足够高，球会越过它（全垒打）。
    落点用一条金色横线表示范围：刚出手时最宽（打得越结实越宽），
      球越飞越近，横线越缩越短，缩成虚线圆时球正好落在那一格。真实落点不会提前告诉你。
    球飞行时每格耗时：滚地每格 1.76 秒、平飞每格 1.92 秒、高飞每格 2.24 秒。
    守方：「左移 / 停止 / 右移」追球——光标落到哪个，野手就朝那个方向匀速跑，
      一直跑到你选「停止」；球比人快，追得慢是正常的。
      不按回车：接球范围小（左右各约 1 格）但稳。
      回车＝起跳：范围变大（左右各约 3 格），但手更糙、更容易脱手；
      起跳后约 1 秒内球必须正好到达才算跳到了，跳早了白跳；
      跳完要缓约 1 秒，这段时间既不能跑也不能再跳。
      记录里会写出「跳起恰好 / 跳起过早」（滚地球是「飞扑」）这样的事实。
    攻方：「撤回 / 停止 / 前进」指挥所有跑者——光标落到哪个，跑者就照那个跑，随时可以改。
      击球后默认是「前进」：打者、被挤着的人和原地站着的人全部跑起来。
      前进：一个垒接一个垒往前跑，不叫停就一直跑，跑回本垒得分。
      停止：跑到下一个垒就站住（已经在半路的人先跑完这一段，没法在半空中停）；
        还没离开垒的人（刚起跑那一拍）直接留在原垒。想让某个垒上的人不跑，要在击出那一刻就按停止。
      撤回：半路上的人调头跑回刚离开的垒；已经跑过多久，回来就要多久，
        回来之前球先传到那个垒就会被触杀。
      被挤着必须前进的人（含打者）第一段不能撤回或留下，选「撤回」「停止」对他们都只是跑到下一个垒。
    球落地后（滚地球不会被接杀），野手要先跑到球位（跑到了自动停住），再选传哪个垒或「不传」：
      四个垒名后面写着传球距离（近绿远红）；传球行的右边写着「垒名 距离」。
      传球按距离和臂力耗时，球到垒那一拍才判：
      被迫进垒的人球先到＝封杀，自己多跑的要触杀，人先站稳＝安全。
      还有人被迫在跑时球会停在垒上，可以接着转传，同一拍两个出局就是双杀。
    接杀高飞球后进入触垒窗口：没提前离垒的人可以赌多进一个垒（牺牲打），
      同样是「撤回 / 停止 / 前进」三个键，这时默认是「停止」：「前进」＝冒险，其余＝不动。
      球会立刻传向他要去的垒，人先到得分，球先到出局。
    出局会写明方式：接杀、封杀、触杀（棋盘中间的判定和记录里都有）。
    同一拍的第三出局是封杀或打者出局时，这一拍跑回来的分不算。

  ◆ 棋盘怎么看
    内野方框：左上三垒、右上二垒、右下一垒、左下本垒；
      实心圆＝有人，空心圆＝空垒，跑动中的人是指向目标垒的箭头。
      方框里三行实时内容：倒数 / 判定（没判定时是双方交牌灯）/ 当前动作。
    底部三条固定轨道：投打 → 外野 → 传球。
      投打行最左是本垒结果符号（空心圆＝还没结果、叉＝挥空、↗ 高飞、→ 平飞、↘ 滚地），
      球从右往左飞，右端写倒数；外野线上是球、野手和落点范围，右端是本垒打墙；传球行右端写「垒名 距离」。
    状态面板四页（聚焦右栏后 ← → 翻页）：局面 / 比分 / 侦察 / 属性。

  ◆ 奖励
    3 局是基准，经验、金币、段位分都按「局数 ÷ 3」缩放：1 局三分之一，9 局三倍。
    3 局：
    胜: +150 经验  +30 金币
    负: +60 经验   +8 金币
    平: +90 经验   +15 金币
    对机器人: 金币按经验的 15% 发放
    中途放弃比赛不判胜负、不发奖励
