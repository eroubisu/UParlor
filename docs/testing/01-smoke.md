# 01 Smoke and lifecycle

前置条件：完成[共享测试环境](README.md#测试环境)，准备两个临时账号 A、B。

## SMK-01 首次注册与登录

**步骤**
1. A 切换到“注册”，依次输入中文用户名和密码。
2. 退出客户端并重新启动，切换到“登录”。
3. 使用同一账号登录。

**预期**
- 每次只提交一次输入，没有重复请求。
- 密码输入不可见；登录后进入大厅并显示正确用户名。
- 重启后账号可登录，客户端没有保存明文密码。

**证据**：脱敏后的登录前后截图。

## SMK-02 三套导航键

**步骤**
1. 分别使用方向键、`wasd`、`hjkl` 移动列表和切换标签。
2. 使用大写 WASD、Shift+方向键、大写 HJKL 切换面板。
3. 使用 Enter/Z 确认，Esc/X/Q 退出或关闭。

**预期**
- 三套键位行为一致；小写移动内容，大写只切换面板。
- 焦点边框、光标和实际接收操作的面板一致。

**证据**：记录覆盖的三套键位及异常。

## SMK-03 根菜单与浮窗栈

**步骤**
1. 用 Space 打开居中的根菜单，只用三套方向键与确认键依次打开聊天、在线、通知、游戏、
   旅伴、档案、设置；同时按 `s/a/o/p` 等旧快捷键。
2. 连续打开两个浮窗，再逐次返回。
3. 重复打开已经打开过的浮窗。

**预期**
- 菜单不显示字母快捷键，旧快捷键不触发窗口；菜单项与确认后打开的目标窗口一致。
- 根菜单只占据中央小块区域，后方主界面保持完整可见；设置中不包含“旅伴设置”。
- 返回严格关闭最上层浮窗，主窗口不消失。
- 重复打开不会产生重复窗口或错乱焦点。

**证据**：浮窗打开与逐层关闭截图。

## SMK-04 断线与恢复

**步骤**
1. A、B 登录后停止本地服务端。
2. 观察连接状态与当前窗口。
3. 重启服务端，重新登录。

**预期**
- 客户端明确显示断线，不把发送失败显示为成功。
- 游戏状态被清理，UI 仍可操作。
- 服务恢复后可以重新登录，不必删除本地数据。

**证据**：断线提示和恢复结果。

## SMK-05 正常退出

**步骤**
1. 打开多个浮窗并启用旅伴后台功能。
2. 保持默认“屏蔽 Ctrl+C：开”，按 Ctrl+C，确认客户端不退出。
3. 从 Space 菜单进入设置，选择“退出 UParlor”并确认。
4. 重启客户端，关闭“屏蔽 Ctrl+C”，再按 Ctrl+C。
5. 检查终端是否立即返回，服务端是否仍正常。

**预期**
- 默认屏蔽时 Ctrl+C 不退出；设置中的退出项以及关闭屏蔽后的 Ctrl+C 都能退出。
- 网络连接和旅伴线程被关闭。
- 无 traceback、挂起进程或持续写日志。

**证据**：退出后的终端输出。

## SMK-06 重复登录处置

**前置条件**：准备同一测试账号的正确、错误密码，并启动两个客户端；这是多客户端用例。

**步骤**
1. 客户端 A 使用测试账号登录并进入一个游戏房间。
2. 客户端 B 输入同一用户名和错误密码。
3. B 改用正确密码，使用方向键、`wasd` 或 `hjkl` 导航，选择“取消登录”。
4. B 再次使用正确密码，选择“结束其他会话并登录”。
5. A 出现“账号已下线”弹窗后选择“返回登录界面”。
6. A 返回登录页后重新输入另一个测试账号，确认连接仍可用。
7. 重复步骤 1、3、4，在 A 的下线弹窗中选择“退出客户端”。

**预期**
- 错误密码只显示密码错误，不透露账号是否在线。
- 输入错误密码后，密码输入框提示改为“密码错误”。
- 正确密码后进入 NORMAL 模式，只显示“结束其他会话并登录”和“取消登录”两个选择。
- 取消后 B 回到用户名输入；接管后 A 安全离开原房间并显示阻断式下线弹窗，B 成为唯一在线会话。
- A 选择“返回登录界面”后显示完整登录界面并进入用户名输入；选择“退出客户端”后正常关闭程序。
- 下线弹窗作为当前活动窗口使用亮边框，底层窗口保持暗边框。
- A 的后续断线不会令 B 下线或从在线列表消失。
- A 回到登录页后旧游戏、在线和浮窗内容不再更新；重新登录后窗口只显示新会话状态。

**证据**：两个选择、取消后的用户名输入、接管后 A/B 状态的脱敏截图。

## SMK-07 服务端信号退出

**步骤**
1. 以非交互方式启动服务端并连接两个测试客户端。
2. 向服务端发送 SIGTERM，等待进程退出。

**预期**
- 服务端只执行一次优雅关闭，刷盘聊天记录并关闭连接。
- 服务端线程结束，启动命令及时返回且无 traceback。

**证据**：脱敏关闭日志与进程退出状态。
