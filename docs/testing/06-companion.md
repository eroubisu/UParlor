# 06 AI companion

> 这些用例会调用第三方 LLM，可能产生费用。使用专用测试 Key 和无隐私测试文本，
> 完成后撤销 Key。任何截图和日志都必须遮盖 Key。

## AIC-01 单窗口与未配置状态

**前置条件**：已登录；测试账号没有 API Key、模型或旅伴配置。

**步骤**

1. 打开旅伴窗口。
2. 使用 `h/l` 在“对话”和“设置”标签间切换。
3. 分别验证无 API Key、无模型、无旅伴和未启用状态。
4. 在每个不可用状态按 `i` 并尝试输入消息。

**预期**

- 窗口默认进入“对话”，没有单独的向导标签。
- 每个状态明确说明缺少的配置，输入保持禁用，消息不能发送。
- “设置”标签可聚焦每个设置项；未选择旅伴时没有“状态”标签。
- 未选择旅伴时右下角不显示名称；选择后只显示当前旅伴名称。

**证据**：未选择时的两个标签、四种禁用状态和右下角名称；不得包含 Key。

## AIC-02 服务、Key 与模型

**前置条件**：使用可撤销的 Gemini 和 DeepSeek 测试 Key；此用例会产生第三方请求。

**步骤**

1. 在“AI 服务”子菜单中分别选择 Gemini 和 DeepSeek。
2. 输入错误 Key，选择“保存并验证”。
3. 关闭并重开窗口，确认错误 Key 未被保存。
4. 输入有效 Key，选择“保存并验证”。
5. 聚焦“模型”并回车，从服务返回的子菜单中选择模型。

**预期**

- Key 输入使用遮罩；选择“保存并验证”前不会写入配置。
- 验证失败显示真实错误且不覆盖原配置；验证成功后仅显示脱敏值。
- 模型只能从当前已验证服务返回的列表中选择，重开窗口后选择仍保留。

**证据**：失败信息、脱敏值和模型子菜单；不得记录 Key。

## AIC-03 创建与切换角色

**步骤**

1. 聚焦“当前旅伴”并回车，选择“创建旅伴”。
2. 在独立创建窗口的第一页按 `i`，输入一段无隐私描述并提交。
3. 依次完成名字、性格、说话风格、外貌、背景故事。
4. 每页验证4个候选项和“重新生成”；按 `i` 输入新值，提交后再从选项中确认。
5. 在属性页按 `i` 后不提交，分别用 `Esc` 和 `Ctrl+[` 退出，再用 `j/k` 导航。
6. 不进入输入模式，直接确认名字候选并进入性格页，检查输入提示。
7. 在下一页仍在生成时返回较早页面，确认候选和当前选择原样保留且没有发起重新生成；再
   进入下一页，确认原生成继续并正常显示结果。
8. 在较早页面修改选择，确认后续已选结果仍保留。
9. 在最终确认页检查汇总，然后选择“创建旅伴”。
10. 再创建一个旅伴并从“当前旅伴”子菜单切换，随后重启客户端。
11. 再次选择一个旅伴，在操作子菜单中选择“删除”，先取消一次，再确认删除。
12. 发送一条超过聊天面板宽度的消息，并让旅伴回复同时包含动作和台词；确认玩家使用三段
    标题，旅伴使用“旅伴名、心情”两段标题。
13. 等待回复期间切换到“设置”和“状态”，并输入一条超过输入框宽度的中文草稿。
14. 在历史内容刚好触发纵向滚动条时，发送一条超过面板宽度且不含空格的 ASCII 消息。
15. 在设置中选择“清空聊天记录”，先取消一次，再确认；切回对话并发送一条新消息，随后
    查看状态页。

**预期**

- 未确认当前页时不能进入下一页；候选项基于描述和此前选择生成。
- 创建窗口打开后，原旅伴设置窗口关闭；创建窗口是唯一活动浮窗并可正常导航。
- NORMAL 模式下 Enter 不会开始文本输入；描述、API Key 和属性内容均只能按 `i` 进入
  INSERT 模式。
- `Esc` 或 `Ctrl+[` 取消未提交输入后立即恢复 `j/k` 导航；输入提示始终对应当前属性页。
- 返回较早页面不会调用 AI，候选和已选项保持不变；重新生成只在明确选择该选项时替换
  当前页候选，修改较早选择不会自动清除后续结果。
- 最终确认前不写入角色；成功后角色被选中且配置持久化。
- 失败不会留下损坏或半写入角色。
- 删除前必须明确确认；确认后该旅伴的设定、对话、记忆和状态一并删除。
- 玩家和旅伴消息使用与其他聊天一致的完整 Powerline 外框。玩家标题为“玩家名、聊天称号、
  等级”，旅伴标题为“旅伴名、心情”并复用玩家前两段样式。模型通过强制结构只生成一组回复：
  最多一个前置的缩进弱化动作行，后面只有一个连续台词区。客户端不得截断、合并或隐藏模型
  生成的第二组内容；结构违约必须明确失败。每条消息显示秒级时间，长内容不破坏外框。
- 回复期间窗口、标签和历史滚动仍可操作，并可继续发送；每条消息保留独立回复位置。长输入
  以单行水平视窗跟随光标，不丢字、不换行，也不从中文字符中间裁切。
- 已有旅伴时首次打开窗口立即显示“状态”标签；回复结束后关系与心情读取最新反思结果，
  已打开的状态页自动刷新。
- 清空聊天记录前必须明确确认；确认后旧对话不再显示，新消息正常出现，但角色、长期记忆、
  关系和心情保持不变。

**证据**：逐页候选、输入值加入选项、确认汇总和重启后的当前角色。

## AIC-04 流式对话与记忆

**步骤**

1. 连续发送三轮包含可验证事实的测试对话。
2. 在第一条回复尚未完成时继续发送第二、第三条，观察输入状态。
3. 重启后询问之前的测试事实。
4. 关闭并重新打开旅伴窗口。

**预期**

- 每轮结构化回复完整有效后才开始逐字显示，不重复、不覆盖其他消息；逐字显示期间输入保持
  可用，中文组合字符和 emoji 序列不被拆开。
- 第一条回复逐字显示期间发送第二、第三条时，新玩家消息依次显示在当前回复下方，并各自
  立即保留回复位置；后续 AI 请求只在前一条回复显示完成后按发送顺序开始。
- 窗口和客户端重开后可见对话与角色记忆均恢复。

**证据**：使用虚构事实的对话片段。

## AIC-08 旅伴状态

**前置条件**：已选择旅伴并至少完成一轮对话。

**步骤**

1. 打开旅伴窗口，切换到“状态”标签。
2. 继续对话使关系或心情发生变化，再次查看状态。
3. 使用无隐私测试文本明确辱骂旅伴，等待回复后再次查看状态。
4. 切换到另一个旅伴。

**预期**

- 选择旅伴后才出现“状态”标签。
- 状态只显示关系阶段、亲密度、信任度、熟悉度和当前心情；不显示内心想法或玩家印象。
- 状态变化符合角色、既有状态、完整互动和实际回复的语义；任何负面互动不得因评估缺失而
  被代码硬编码为正向关系增长。
- 状态属于当前旅伴，切换旅伴后同步切换。

**证据**：两个不同旅伴的状态页；不得包含私聊原文。

## AIC-05 主动搭话与关闭

**步骤**

1. 启用旅伴和“允许主动搭话”。
2. 分别触发私聊、好友申请、游戏邀请和系统通知。
3. 在 UNO 和飞行棋中分别触发开始对局、轮到自己和对局结束。
4. 保持沉默至时间触发条件成立。
5. 在旅伴窗口关闭时收到主动消息，检查右下角旅伴徽章；打开旅伴窗口。
6. 在主动回复已经生成、但界面尚未显示的瞬间发送一条玩家消息。
7. 关闭后台主动，再等待一个 tick 周期。

**预期**

- 启用时，时间条件及外部重要事件均可触发主动消息。
- 游戏重要事件由对应游戏定义，不由通用框架按游戏 ID 分支判断。
- 每局游戏只在结束时产生一次旅伴主动通知；开始和每次轮到玩家均不产生通知。旅伴可在确实
  想了解比赛时调用游戏观察工具，普通更新不会触发回复。
- 窗口关闭时显示独立旅伴未读数；打开后未读数清零，但聊天记录保留。
- 旅伴未读使用爪印符号；主动触发所用的系统上下文不显示、不写入对话历史。
- 对局结束事件尚未主动显示时立即向旅伴发消息，只收到一条回复；该事件可影响这条回复，但
  后台恢复后不得再补发第二条。已经排队等待界面显示的旧主动回复也必须作废，取消中的半截
  主动回复不得写入历史或在重开窗口后出现。
- 关闭后不再调用或显示主动消息。
- 后台线程不阻塞 TUI。

**证据**：主动消息和关闭后的观察时间。

## AIC-06 玩家隔离

**前置条件**：账号 A、B 和同名账号 A 的两个独立客户端 State；使用无隐私测试消息。

**步骤**

1. 使用账号 A 配置角色并产生测试历史。
2. 在工具调用或流式生成尚未完成时退出，随后登录账号 B。
3. 替换 State 后再次以相同用户名 A 登录。
4. 再切回最初账号 A。

**预期**

- B 看不到 A 的角色选择、历史和关系状态。
- 旧生成结果不会进入 B 或同名新 State；工具只看到当前账号的 State 快照。
- 退出/换 State 会停止并 join 旧后台工作，且客户端不创建私聊持久副本。
- A 恢复自己的配置；全局 provider 配置按设计共享。

**证据**：A/B/同名新 State 的无隐私工具结果和后台线程状态。

## AIC-07 网络错误与退出

**步骤**

1. 对话生成时断开网络。
2. 恢复网络后再次发起对话。
3. 生成或后台 tick 期间退出客户端。

**预期**

- 错误被显示，输入恢复可用；恢复后无需删配置。
- 退出不挂起，不留下 companion 后台线程。

**证据**：错误、恢复和退出终端状态。
