# 07 Release manual checklist

发布负责人复制本表到 PR 或发布记录，填写用例结果和证据链接。`PASS` 之外的结果必须有
明确风险接受人；不得用“代码看起来没问题”代替执行。

## 每次发布必跑

- [ ] `pwsh -File tools/check.ps1`
- [ ] SMK-01 注册/登录
- [ ] SMK-02 导航
- [ ] SMK-03 浮窗栈
- [ ] SMK-04 断线恢复
- [ ] SMK-05 正常退出
- [ ] SMK-06 重复登录处置
- [ ] SMK-07 服务端信号退出
- [ ] UI-01 中文与组合字符
- [ ] UI-03 Nerd Font 单色着色
- [ ] UI-05 浮窗覆盖中文边框
- [ ] SOC-01 在线状态
- [ ] SOC-03 世界/房间聊天
- [ ] SOC-04 私聊未读
- [ ] SOC-06 并发好友变更
- [ ] SOC-07 私聊会话清空
- [ ] SOC-08 聊天日志日界轮转

## 按改动范围追加

| 改动范围 | 必跑 |
| --- | --- |
| Textual、窗口、CSS、字符 | UI-01 至 UI-07 |
| 登录、网络、服务端生命周期 | SMK-01、SMK-04 至 SMK-07 |
| 好友、聊天、通知、邀请 | SOC-01 至 SOC-08 |
| UNO 或通用游戏框架 | UNO-01 至 UNO-08 |
| Ludo 或 Bot 调度 | LUD-01 至 LUD-09 |
| 旅伴、LLM、玩家本地数据 | AIC-01 至 AIC-07 |
| 奖励、段位、持久化 | 对应游戏结算用例并重登验证 |
| 依赖或 Python 版本 | Python 3.10 与当前开发版本各执行 smoke |

## 发布记录

```text
Commit/版本:
执行人:
日期:
OS/终端/字体:
Python:
自动检查:
人工用例:
失败与风险接受:
```

发布前另行确认：

- [ ] 未跟踪 `.env`、Key、日志、玩家数据或临时目录
- [ ] 客户端与服务端版本和变更说明一致
- [ ] Dependabot/CI 无未处理的阻断项
- [ ] 只有收到明确发布指令后才运行上传或部署脚本
