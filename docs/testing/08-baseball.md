# 08 棒球

前置条件：两个客户端会话 A、B（或 A + 1 个机器人）；终端至少 88×32。

## BASE-01 建房、开局与角色分配

**步骤**

1. 选择棒球创建房间，添加机器人或让 B 加入并准备。
2. 未满 2 人时尝试开始；满员后开始。
3. 观察开局后的棋盘画面与右栏状态面板。

**预期**

- 未满 2 人不能开始，提示当前人数与“返回”。
- 开局随机决定谁先攻；局数是房主创建房间时选的（默认 3 局，见 BASE-13）。
- **棋盘占满棋盘区**：内野是四条边都画通的正方形，垒包就是四个角（垒名在方框外面，
  标记与线之间有空隙），外野线把 12 格摊到整幅宽度；最小窗口（88×32）下不出现滚动条，
  窗口变大时图形一起变大。
- 实心圆＝有人、空心圆＝空垒、箭头＝正在跑向该垒、打者在本垒；不出现任何号位数字或比分文字。
- 右栏状态面板有四页标签（局面 / 比分 / 侦察 / 属性），聚焦右栏后 ← → 可翻页；第一页是局面。
- 状态面板用符号代替长句（出局＝三个圆点、体力＝⚡）；
  **两列各贴一边**（标签左对齐、值右对齐，值共用同一条右边缘，**左右各缩进 2 格**，
  不贴边框）；**没有冒号、逗号、句号、括号**；行太长时先砍值的尾巴（`…`），标签永远完整。
- **行位固定、只放棋盘上没有的**：局面页永远这 5 行
  `局数 / 比分 / 出局 / 球数 / 体力`——**其它东西棋盘上本来就在显示**
  （这一拍在干什么、交牌灯、球位、落点、野手、跑者进度、传球目标），右栏不再重复。
  走查时最容易看出的回归：这些行**不许上下挪动**，行数永远是 5（侦察 6、属性 4）。
- **交牌灯在棋盘中间那一槽**：出牌期间写 `投 ●  打 ○`（空心＝还没交、实心绿灯＝已交）；
  上一拍的判定（如 `安全 SAFE`）在它上面自己的一槽，**不顶替灯**；右栏不再有「就绪」行。
- 局面页按美职棒：局数 `2/3 ▲` / `2/3 ▼`（当前局 / 总局数，上半/下半三角）、球数写成 `坏球-好球`
  （如 `3-2` 满球数）、客队在前 `bob 0 - 0 alice`。
- **比分页**：`局 1 2 3 合计` / `bob 0 1 - 1` / `alice 0 2 - 2`，逐局得分 + 合计，客队在前；
  还没打到的半局写 `-`；9 局时数字仍然两列一格、名字过长被截断但数字完整。
- **不写阶段、不写球种、不写帧号**：这一拍在干什么由棋盘中间那一槽写；
  自己刚选的球种/区域/力度不在右上角回显（用户 2026-10-16 报的问题）。
  播报只在下方日志。
- **面板高度 8 行**（正文 6 行 ＝ 侦察页的固定行数）：不会多一行、不会把聊天挤下去，
  多出来的行留给聊天区。
- 侦察页每一球两行（`1 守 四缝线速球 好球带边缘 标准` / `  攻 alice 标准挥击 → 界外`），
  固定 3 槽，**一行放得下、不出现「…」**；攻守交换后老的几球写的还是当时的打者；
  属性页是 `我方投手 控球 5 球速 6 变化 4` 这样的完整短词，固定四行。
- 右下角只出现房间级操作（放弃），没有布阵/投球/打击这类玩法指令。

**证据**：等候室与开局面板截图。

## BASE-02 两级菜单、同时出牌与确认

**前置条件**：两个客户端会话（A 守方、B 攻方），或一人对机器人。

**步骤**

1. 双方开局后同时看棋盘下方的一级菜单：守方是「布阵 / 球种 / 区域 / 力度 / 确定」，
   攻方是「预判 / 挥棒 / 确定」；**垒上有人时**守方在「确定」前多一项「跑者」（牵制），
   攻方在「确定」前多一项「盗垒」——两张表单都是设置项在前、「确定」在最后；垒上没人时这两项不出现。
2. 回车进入「布阵」，观察框内第一行是不是出现标题「布阵」，再在二级菜单里换一个站位。
3. 在二级菜单里选「返回」，观察是否回到一级（标题消失）且取值未变。
4. 走到最后一项「确定」，观察是否再问一次；分别选「否」与「是」。
5. 只让守方交牌，盯**棋盘方框中间那一槽**的「投 … 打 …」两个灯与攻方是否开始动画；
   再让攻方交牌。
6. 两边都交完之后盯棋盘上投打行最右端：应当出现 `3`，一秒一跳变成 `2`、`1`；
   **数完球不会自己出手**——投手那边这时亮起「投球」键，他按下这一球才投出去。
   这几秒里再试着改布阵 / 球种 / 挥棒，看是不是都改不动了。

**预期**

- 一级菜单每行只有“项名 + 当前取值”（如 `> 布阵  标准站位`）；**一级主盘没有标题行**。
- 二级菜单**第一行是这项的名字**（如 `布阵`、`球种`、`盗垒`），操作区总高固定 8 行，
  换菜单不会让棋盘长高变矮；**只列出取值名字 + 「返回」**——不写概率、不写效果、
  不写“已选/不改这一项/按当前设置投出”这类说明句子；游标默认停在该项的当前取值上。
  （作用只有玩家自己从侦察页、帮助与实际结果里研究出来。）
- 布阵选中即刻生效（一级菜单右侧的取值同步更新），二级菜单的「返回」不改任何取值。
- 「确定」是最后一项，进入后只有「是 / 否」；选「否」回到一级菜单，选「是」才交牌——
  **交牌后确认菜单立刻消失**，操作区回到当前阶段的菜单（不会卡在"是/否"上）；
  打者交完牌，操作区立刻换成那颗「击球」键（这时它还按不动，见 BASE-03）；
  投手交完牌同样立刻拿到「投球」键（数完倒数才亮，见 BASE-03）。
- **同时出牌**：两边各自交牌、互不等待；**交牌那一球锁定**（再改布阵或走菜单都不生效），
  「投 … 打 …」两个灯用空心圆 / 实心绿灯表示两边交没交（在棋盘方框中间那一槽）。
  两边都交完后不另发播报（两盏灯就是提示），
  接着**倒数 3→2→1**（一秒一跳，写在棋盘上投打行的右竖线右边、贴棋盘右边缘；
  **不写进右栏状态面板**——实时内容都在游戏面板上），数完才开投。
  倒数期间两边都改不了牌，两个灯继续亮着。
- **二级菜单第一行是这项的名字 + 一根横杠**（走查 `布阵` / `球种` / `区域` / `力度` /
  `跑者` / `盗垒`）：标题独占一行，下面一根 `─` 铺满操作区，再下面才是取值列表。
- **动画期间操作区先放下一刻的菜单**：一级盘不写标题（标题只属于二级菜单），
  游标能挪（颜色变淡），回车按不动；动画结束、阶段一到，同一个菜单原地生效
  （游标停在你摆好的地方）。
  传球途中同理：守方能提前看到能传给哪些垒；**球一出手，守方那边就是跑位盘**
  （左移 / 停止 / 右移，暗着，球被打出来那一刻原地亮，回车起跳也在那一刻才生效——
  球还没被打出来时没有球可接，回车按不动）。
- 预告期间**不出现攻方跑垒按钮**，回车也不能起跳——球有没有被打中要到
  揭晓那一帧才能看出来；守方的跑位盘可以预告（他本来就是要追球的人，不泄密）。
- **上一球的设置整场保留；交过一次牌之后，下一球表单的光标直接停在「确定」**：
  原样再来一球只要 回车 → 回车；开局第一球光标仍在第一项。
- 选择菜单只发给决策者：对手在结算前看不到投了什么，**也看不到攻方排了盗垒**
  （盗垒在投手投出这一球之后才出现在棋盘上）；结算后才在“侦察”页与日志中出现。
- 力度“全力”比“标准”更快掉体力，体力低于阈值后控球与球速下降。

**证据**：两个客户端在结算前后的面板对比、二级菜单标题与就绪灯各一张截图。

## BASE-03 读投手：预判、挥棒与按键时机

**步骤**

1. 连续投同一种球，让攻方在侦察页看到规律。
2. 攻方按“预判球种 → 挥棒类型”两步出棒并确认，分别试“预判正确”“预判错误”，
   挥棒分别试「标准挥击 Standard Swing」「大力挥击 Power Swing」「滚地球 Ground Ball」
   （菜单里没有「等球」：不按击球键就是放过去）。
3. 交完牌后在等对手 / 倒数 3→2→1 的这几秒里按几下「击球」（应该毫无反应：不发指令、
   不弹提示），然后球从投手那边飞过来时再按——分别试“球刚出手就按”“球到一半按”
   “球快到了才按”、“球已经到了本垒（挥棒段）才按”，以及“一次都不按”。
4. 观察投球到出棒之间的两段动画与最终的球数变化（好球、坏球、界外、挥空、保送、三振）。
5. 故意在坏球区投球，让高选球的打者挥棒，观察是否出现「收棒」播报。
6. 打一个滚地球：它**不会被接杀**——球滚到野手脚边，野手捡起来传垒，
   打者要在一垒被封杀才算出去；球到得慢就是内野安打。

**预期**

- 判对球种且按在正确的时机档上时明显更容易击中并打出长打；预判错并且大力挥击时更容易挥空。
- 时机档的对应关系仍然按球种推算（全力直球要提前、变速球要延后），只是现在要靠手感按出来，
  菜单里也没有这个选项了。
- **按下击球的瞬间，操作区立刻换成跑垒布局**（撤回 / 停止 / 前进，默认停在「前进」），
  不用等服务器回执；球被打到场内时这三个按钮已经在手上。
- **投打过程里「击球」键一直不消失**：球到了本垒（挥棒段）也还在、还能按，
  这一按算「延后」（球已经到板前，那一挥通常没好结果）。键不许中途被别的菜单顶掉——
  顶掉就会误触旁边的选项（用户 2026-10-15 报的问题）。
- **击球键从交牌那一刻就在（用户 2026-10-15 定）**：等对手、倒数 3→2→1 期间都看得见，
  但**球没投出来之前按不动**——按回车既不发 `/hit` 也不给提示（就是没反应）；
  投手按下「投球」的那一刻同一个键亮起来，游标不跳位、不换菜单。
- **倒数数完要投手按「投球」才开投（用户 2026-10-16 定）**：倒数完他不按，球不会动；
  这颗键从交完牌就在他手上（等对手 / 倒数期间都看得见、按不动、不给提示），
  亮起来之后按下去才开投；按下的时机**不算进任何判定**。
  投出去之后他的面板换回投球表单当预告，可以先把下一球挑好。
- 投打分两段：**投球段** 9 帧 ×140ms ≈ 1.26 秒（球在本垒行上**从右往左**飞，
  右端是投手、左端是本垒）、**挥棒段** 3 帧 ×140ms ≈ 0.42 秒（球停在本垒那一端，
  本垒符号在最后一帧按结果变：叉＝挥空、↗＝高飞/全垒打、→＝平飞、↘＝滚地）；
  结果在动画结束才揭晓；动画期间打者屏幕上看不到球种，双方也看不到结果。
- **动画必须连着滑、而且跟着服务端的时钟走（2026-10-21）**：客户端按时间连续滑动（约 30fps），
  每一拍到来就朝**下一拍的位置**滑，滑完正好下一拍到来。走查：
  ① 投手一按「投球」、球**立刻**从投手那端动起来（不再先在手上停一拍）；
  ② 球被打出的瞬间，外野线上的球**立刻**开始动（高飞球以前要纹丝不动 2.24 秒）；
  ③ 球飞到落点那一拍，画面上的球正好到落点，**最后一格不会突然跳一下**；
  ④ 球在拍内只会前进、不会倒退、不会突跳；⑤ 球压在投打行的分界线上时按键，
  日志里的「时机」和你看到的档位一致（网络延迟在 280ms 内也一致）。
- **投打行上有两条淡色分界线 `┆`**，把球路分成 提前 / 正常 / 延后 三档：
  球越过线的那一刻就是换档的那一刻（走查：球压在线上时按一下，对照日志里的「时机」）。
  **打者一按下击球，本垒处立刻亮起实心金点**（本地先亮，不等服务端回执；对手的屏幕上随回执亮起，
  挥棒是公开动作）；按下之后即使服务端发来一份旧数据也不会闪回「没挥」；
  结果揭晓后换成结果符号。线、点、球在每档窗口宽度（46/58/78/88/98 列）下都不挤动别的东西。
- **揭晓时记录栏里是一行**：`挥空 0-1 时机提前 预判正确`（时机和预判两个词组只在打者挥了棒时出现；
  只陈述事实，不评价、不给建议）。
- **慢放**：投打与其余动态阶段均慢 2 倍；只拉长每拍时长、**拍数一个不动**。
  走查时量一下：滚地每格 1.76 秒、平飞 1.92 秒、高飞 2.24 秒；捡球 / 传球一拍 1.12 秒，
  地面 / 传球阶段速度 5 跑一个垒约 7.84 秒；倒数仍是 1 秒 1 跳。
  飞行期间跑者与球同步推进；若速度 5 的跑者全程都处于飞行阶段，跑完一垒分别需
  12.32 秒（滚地）、13.44 秒（平飞）、15.68 秒（高飞）。飞行不足 7 拍时，剩余拍数继续按地面阶段推进。
- **时机不是选项，是按键**：投打过程里打者的操作区只有一颗「击球」，
  按下那一帧决定时机档（投球段：前 45% 提前 / 前 80% 正常 / 之后延后；挥棒段一律算延后）；
  不按＝这一球放过去（判好坏球）；按了但没对上时机照旧可能挥空，不是一定出局。
- 挥棒先判“接触率”（基础 0.80，惩罚按比例扣，见 [设计文档](../design/baseball.md)）：
  没打中里 55% 挥空、45% 界外。**三种挥棒是真取舍**：同一球读准 + 时机对上时，
  标准挥击进场约 84%，大力挥击只有约 61% 但长打与本垒打更多，滚地球进场率最高、绝无长打；
  **不存在永远更好的那一项**。
  **选球**高的打者在坏球区更容易及时收棒——收住时播报 `收棒 坏球 …` 并按好坏球计入球数。
- 4 坏球保送、3 好球三振；两好球后的界外球不增加好球数。
- 侦察页按顺序显示最近几球的球种（中文短名，如 `四缝线速球`）、结果、区域、力度与挥棒方式。
- 击球质量只认"读准球种 + 对上时机 + 双方属性"：读错两处时基本打不出长打，
  也几乎不可能全垒打。

**证据**：两段动画各一帧、侦察页、三振/保送/长打/收棒四种结果截图。

## BASE-04 外野连续追球、落点范围与回车起跳

**步骤**

1. 打出各种球型（滚地、平飞、高飞），观察外野线上的球从 1 号位起飞、逐格推进，
   以及外野线上那条金色横线（落点范围）的变化。
2. 用 `→` 把光标挪到「右移」追球（光标落下野手就开始匀速跑，一直跑），想停就把光标挪回「停止」。
3. 球快到的时候按一次回车起跳：分别试 ① 球到之前约 1 秒内按（时机对）；② 球还很远就按（跳早了）；
   ③ 跳完立刻再按回车、再挪光标（缓冲期间应该既跑不了也跳不了）。
4. 分别在“站位正确”“差 1 格”“差 3 格以上”的情况下，对比起跳与不起跳的接球结果。
5. 飞行期间由进攻方下达一次跑垒指令，观察球仍按原节奏逐格推进。

**预期**

- 球从 1 号位起飞、停在落点，**一格一拍**（滚地每格 1.76 秒、平飞 1.92 秒、高飞 2.24 秒；
  整段 1.76–24.64 秒，见设计文档的各球型范围），球在拍内连续滑动，**画面球位＝服务端真实位置**
  （只晚一个网络延迟），野手＝人形、球＝红色实心圆。
- **落点范围一路收窄**：球一击出，外野线上出现一条金色细横线（`╶────╴`），含真落点但不在正中；
  球越飞越近，横线越缩越短，窄到不足一格就收成虚线圈，**球到的那一拍正好落在圈上**。
  打得越结实，刚出手时横线越宽。横线在每档窗口宽度（46/58/78/88/98 列）下都不顶宽这一行。
- **野手像球一样丝滑**：按住方向就一直匀速滑，不是一格一跳、不是走一下停一下；
  光标挪回「停止」就停在那里；跑到边线自动停。球越远他越慢（整段飞行总共跑约 3 格，速度≥7 的双倍）。
- **回车＝起跳**：三个按钮上回车都一样。起跳后野手在空中约 1 秒（画面上是亮白色），
  落地后缓冲约 1 秒（暗灰色）；缓冲期间位置不动，缓冲完按住的方向接着跑；两边屏幕都看得到。
- 起跳后的接球结果：正好在空中球到 → 范围大（约 3 格）但更容易脱手；
  跳早了落地时球还没到 → 按没起跳算；通知栏会写 `起跳时机 恰好` 或 `起跳时机 过早`，
  动作名按球型叫：滚地球＝飞扑接球，空中球＝跳跃接球。
- **不再有「普通 / 跳跃 / 飞扑」三选一，也没有最合适动作的金边提示**；操作区飞行时只有左移 / 停止 / 右移一排。
- **本垒打墙在外野线最右端**（格点铺完后剩下的列全归它，一直铺到棋盘右边缘；
  另外两行同列位留白，三行仍然等长），而且**每一拍都在**——不随阶段出现或消失。
  全垒打的红球停在墙上、外野线上不再有球，这一拍保留到下一次投球前，所以"越过墙"看得见。
- **投打进度条与外野线一样长**（同一个 5 列前缀 ＋ 同一段 12 格宽度，两端收在同一个地方）。
- **跑垒有动画**：四条垒线（本垒→一垒→二垒→三垒→本垒）上，正在跑的人是指向目标垒包的
  箭头，按每拍进度连续滑动；站着不动或出局的人只由角上的实心/空心标记表示。
  击出的瞬间打者就开始往一垒跑，被挤的人同时开跑。
- 外野线下方不再有号位数字；球与野手的位置**画在这条线上**，
  落点的大致方位（如“中线偏右”，按范围正中算、随范围收窄一拍拍更准）写在棋盘中间那一槽里，不在右栏。
- **方向键只挪光标**：`←` / `→`（含 `h` / `l`）在同一行里挪一格、`↑` / `↓` 换行，
  挪到行尾会**环绕**回行首（和 UNO / Ludo 的按钮行、和所有菜单同一套语义）；
  光标落到哪个按钮，哪个按钮生效（追球是持续状态，一直跑到你挪回「停止」）。
- **四种动画都是逐帧滑动**（不是一格一跳）：球、野手、跑者、投打球路。野手由服务端给位置、方向、速度，
  客户端按时间匀速滑；方向由服务端记着，**客户端不用每拍重发**；你按键后约一个网络往返就看到他动。
- 飞行中的跑垒操作不会重复启动计时，也不会让当前球格提前推进；切换到下一阶段后，
  下一拍按该阶段完整的拍长等待。
- **打得越结实越难接**：质量越高，刚出手时范围越宽，而且即使站对位置也可能脱手，
  所以球落地主要来自强击球，而不是靠野手看错。
- 差 1 格以内通常接杀（不起跳）；差 1–3 格靠起跳在空中接；差距过大球落地——**落地不等于安打**，进入下一项捡球流程。
- 窗口较窄（游戏区最小宽度）时菜单仍在固定高度内滚动可见，棋盘会省略距离标注。

**证据**：三种球型各一张飞行中（横线宽 / 窄 / 缩成圈）与落地后的截图；一次起跳在空中和缓冲中的截图。

## BASE-05 落地捡球、传球距离与跑垒

**步骤**

1. 打出会让球落地的击球，落地后用 `→` 把光标挪到「右移」追球（一直跑），想停就挪回「停止」。
2. 站到球位上，观察菜单是否换成四个垒包 + 「不传」，以及每个垒包后面的距离。
3. 传向最远的垒与最近的垒，观察跑者在球到垒前是否站稳、是否被封杀。
4. 观察棋盘：外野线上的球与野手、传球行的进度；传球信息（目标垒 + 距离）
   与跑者进度都在**棋盘上**（传球行右端写「垒名 距离」、垒名行写四个距离、
   跑者是垒线上的箭头），右栏只有比分牌，没有这些。
5. 在捡球阶段发出跑垒指令，并在不同时间点开始传球；观察操作不会让同一阶段重复计时，
   阶段切换后传球仍按完整拍长推进。

**预期**

- 落地后不会直接判安打：野手必须先跑到落点（菜单只给左移 / 停止 / 右移），站上球位才出现传球菜单。
- 传球按钮只写动作名（`传一垒`），**距离写在棋盘垒名行上**（如 `一垒 46.1米`），
  颜色按远近平滑变化：最近的偏绿、最远的偏红，中间的连着过渡；
  球一被打出去（飞行阶段就有）就该看到这四个数字，不用等到落地。
  操作面板不写说明性数据；选「不传」再回车则控球结束这次击球。
- **传球也有飞行进度条**：三条固定行里最下面那条「传球」行上，第 1 格是野手，
  **球从最左一格走满整条线到最右一格**（整条线＝这次传球的距离：距离远就多走几拍、
  走得慢，不许只走半截），**右竖线右边的留白里写「垒名 距离」**（如 `二垒 15.7米`，总距离，
  传出去后不变）；留白放不下时先去掉垒名（`15.7米`）、再去掉单位（`15.7`），
  **这一行不许被顶宽**（46/58/78/88/98 列都要看一眼，右竖线必须和另外两行同列）；
  球从传出的那一刻就开始动、最后一拍正好落在最右格；到垒那一拍才判：被迫进垒＝封杀、自己多跑的＝触杀、先站稳＝安全。
- 棋盘上四个垒名的后面同时写着对应距离（如 `一垒 46.1米`），越近越绿、越远越红，
  球要去的垒包整角高亮。
- 传球按距离与臂力耗时（每拍 1.12 秒），期间双方都不用按键；球到垒时若跑者未站稳即封杀（出局 +1），
  否则安全。
- **击出后默认全体前进**（光标停在「前进」）：打者、被挤的人和原地站着的人一起开跑，
  不叫停就一直往前跑；想留人在垒上，要在击出那一刻按「停止」。跑者的进度画在**棋盘**上
  （正在跑的人是垒线上指向目标垒的箭头，一拍一拍滑过去），右栏不写。
- **跑垒画在棋盘上**：正在跑的人是指向目标垒包的箭头，沿垒线一格一格滑动
  （向右／向上／向左／向下就是四条边线的方向）；站着不动或出局的人只留角上的标记。
- 垒包方框的占用标记随结果更新：有人＝实心圆、空垒＝空心圆、本垒始终是打者。

**证据**：落地捡球、传球选择、封杀与安全各一张截图。

## BASE-06 跑垒指挥（撤回 / 停止 / 前进）与盗垒

**步骤**

1. 先让一垒有人（打一个安打或保送都行），下一棒击出后盯着四条垒线。
2. 击出瞬间看棋盘：光标应该已经停在「前进」；打者、被挤的跑者、原地站着的跑者是不是**都**在跑。
   不动操作区，他们应该一个垒接一个垒一直往前跑。
3. 再来一次，击出后立刻把光标挪到「停止」：原地站着的人应该留在垒上，打者和被挤着的人
   跑到下一个垒就站住；晚一拍再按，已经跑出去的人跑到下一个垒才停（半路上的人先跑完这一段）。
4. 让二垒有人（没人挤他），击出一个飞得很久的高飞球，保持「前进」，等他离开二垒一段后
   把光标挪到「撤回」：箭头应该**调头**，从当时的位置往回滑到二垒，没有瞬移；
   再挪回「前进」，他又调头往三垒跑。
5. 同样的场景，撤回之后让守方把球传向二垒：他还没回到二垒就被触杀（播报是「触杀」，不是「封杀」）。
6. 打者和被挤着的跑者第一段跑的时候选「撤回」：他们**不会**调头。
7. 在出牌阶段看打击表单里的「盗垒」项（垒上有人时才出现），
   进去挪到「领跑者盗垒」，观察投打两段动画里跑者是不是在跑、动画结束后播报是什么。
8. 把三垒有人时的「全体盗垒」试一次（盗本垒＝直接得分）。
8a. 一垒有人时选「领跑者盗垒」，让打者挥棒击中：盗垒的人应该留在二垒（日志 `盗垒成功 一垒跑者上二垒`），
   击出后从二垒起跑，**不会**先退回一垒；三垒盗本垒再被击中，当场得分。
9. 留意出局时的字样：接杀、封杀、触杀都要写出来——棋盘中间那一槽（`接杀 FLY OUT` /
   `封杀 FORCE OUT` / `触杀 TAG OUT`），记录栏最后一行的出局播报里也有
   （如 `接杀 落点中线 野手中线 1出局`、`封杀 二垒 一垒跑者 1出局`）。

**预期**

- 「盗垒」菜单（`领跑者盗垒 / 保持 / 全体盗垒`）只在出牌阶段的打击表单里；击出后的按钮盘是跑垒盘
  （`撤回 / 停止 / 前进`）。跑垒盘里光标挪到哪个按钮，哪个按钮就生效，不用回车；
  盗垒菜单里选值只改本地，要「确定 → 是」才随牌交出；
  `← →` 在三个按钮之间挪一格，挪到头**环绕**回另一头（和所有菜单同一套语义）。
- 一排三个键管**所有跑者**（用户 2026-10-21 选了一排，不再有「只派领跑者」）。
  「前进」（击出后默认的光标）＝不叫停就一直跑；「停止」＝跑到下一个垒就站住，
  还没离垒的人直接留下；「撤回」＝半路上的人调头回刚离开的垒，已经跑过多久回来就要多久。
- 高飞被接杀时，已经离垒（含默认前进跑出去的）的人是「提前离垒」：可能被双杀，也不再有触垒窗口；
  想踩垒等接杀就要在击出那一刻按「停止」。
- 盗垒在投打两段动画里跑（动画结束正好到垒），结果在揭晓那一帧定：成功＝安全进入下一垒、三垒成功＝得分、
  失败＝被触杀出局（播报 `盗垒成功 一垒跑者上二垒` /
  `盗垒失败 触杀 三垒 二垒跑者 1出局`）。
- 接杀后跑者回原来的垒；半路上离开了垒的人可能被双杀（播报 `双杀`，出局数 +2）。
- 盗垒是**交牌内容**：打击表单里选好、「确定 → 是」时随牌交出，开投前对手的屏幕上
  没有任何起跑痕迹；投手把球投出去之后，跑者才在垒线上跑起来（两边都看得到，守备才有机会抓）。
  右栏不写「领跑者盗垒」（右上角只留比分牌）。垒上没人时表单里没有「盗垒」项。
- 本次击球结束时，播报只列**还没说过**的结果：出局的人在出局那一行已经说了（不再重复），
  站着没动的人不提；其余每名跑者写成 `一垒跑者上二垒` / `三垒跑者得分`，打者写 `打者上一垒`；
  最终垒位播报与棋盘一致。

**证据**：击出瞬间、按下「前进」之后、半路「撤回」调头、盗垒成功与盗垒失败各一张截图。

## BASE-07 两个人同桌（保密与各自的菜单）

**前置条件**：多客户端用例——需要两个客户端会话（A、B）同时在线，双方都当真人操作。

**步骤**

1. 用两个客户端（或一个客户端 + 一个机器人）开局，双方都当真人操作。
2. 守方选球种 / 区域 / 力度并投出，观察攻方屏幕上此刻显示了什么。
3. 攻方选预判 / 挥棒，投球段里按「击球」把这一棒的时机按出来，观察守方屏幕上此刻显示了什么。
4. 攻方有一人上垒后，在出牌阶段进打击表单的「盗垒」项选「领跑者盗垒」，再看守方屏幕上的跑者动画。
5. 全程确认两边棋盘都在实时更新（比分、出局、球数、阶段名）。

**预期**

- 守方投出后，**攻方屏幕上不出现「投出 …」这类文本**（球种/区域/力度只进投手自己的屏幕），
  攻方只会看到阶段变成“打击”并拿到自己的打击菜单。
- 投打动画播放期间，**打者的棋盘数据里没有球种**（动画那行的标签为空，`/pitch` 的载荷也不含
  球种），而且**双方都看不到结果**——侦察板上这一球要等动画最后一帧才出现。
- 攻方的打击选择同样不广播给守方；结果在投打动画播完后两边同时看到。
- 两边的按钮盘互不错位：投球/打击菜单只在各自一方，跑位与接球按钮只在守方，
  跑垒按钮只在攻方；**任何阶段操作区都有按键**（能按的亮着、还不能按的暗着当预告），
  不留空面板、不留死菜单。
- 盗垒是交牌内容：攻方交牌后、投手投出之前，守方屏幕上**看不到**任何起跑的人；
  球投出去之后两边都看得到跑者在垒线上跑。
- **守方能治盗垒**：垒上有人时守方的投球表单里才有「跑者」项，选「牵制跑者」再投，
  同一位跑者的盗垒成功率**减半**；代价是打者那边更好打（接触率 +8%）。
  垒上没人时这一项不出现。

**证据**：两个客户端并排截图（投球瞬间、盗垒瞬间各一张）、牵制跑者的一次成功抓人。

## BASE-08 结算、放弃与断线

**前置条件**：多客户端、长时用例——两个客户端会话，打满房主选的局数（长时用例建议选 3 局）；放弃与断线各测一次。

**步骤**

1. 打满 3 局结算，比较双方经验、金币与段位变化，并重登验证持久化。
   另外各走一次提前结束：① 末局上半结束时让主队领先；② 末局下半主队反超；③ 打平。
2. 对局中确认放弃比赛。
3. 对局中让一方断线。

**预期**

- 局数结束后给出比分与奖励，“局面”页出局用三个圆点表示（实心＝已用掉的名额），
  奖励只发一次，重登不回退。**奖励按「局数 ÷ 3」缩放**：1 局赢一场约 50 经验、3 局 150、9 局 450
  （负 / 平同比例，金币与段位分同比例）；打机器人时金币仍是缩放后经验的 15%。
- **结算在记录栏里是一行**：`获胜 3-1 经验+150 金币+30 段位+10`（**自己的比分在前**：输的一方看到 `落败 1-3`）；
  记录窗口里它前面依次是：`比赛结束 bob 1-3 alice 胜者 alice`、逐局比分两行
  （`客 bob  0 1 0 | 1` / `主 alice  2 0 X | 2`，不必再打的下半局写 `X`）、
  双方战报两行（`bob 安打3 全垒打0 保送0 被三振1`）。
- **标准终局**：① 末局上半结束时主队已经领先——日志写
  `第N局上半 {主队} 已领先 不打下半局`，下半局不打，直接结算；
  ② 末局下半主队一取得领先（含保送、盗垒得分）——日志写
  `第N局下半 {主队} 取得领先 提前结束`，立刻结算、不必打满三个出局；
  ③ 打满仍平手＝平局，日志写 `比赛结束 … 平手`，按平局发奖励，不加赛。
- 放弃＝中止比赛：房间回到等待室、重开一局，**双方都不发奖励**（和 UNO / Ludo 同一语义）；
  断线也是中止：比赛结束、**不判胜负**、双方不发奖励，只向幸存方播报一句。
- 返回等候室后重开一局，局数、出局、垒包、球数与比分全部重置。

**证据**：结算面板、放弃后回到等待室、断线播报各一张截图。

## BASE-09 按钮盘：方向键只选选项，光标落下就执行

**步骤**

1. 击出一个高飞球，守方视角看操作区：应该只有一行按钮
   `左移 / 停止 / 右移`（没有接球动作那一排），光标默认停在「停止」。
2. 按 `→`：光标挪到「右移」上，**光标一落下野手就开始往右匀速跑**（不用回车），
   然后**不要再按**，看他是不是一直往右跑。
3. 再按一次 `→`：光标**环绕**回「左移」（和 UNO / Ludo 的按钮行、所有菜单一致），
   野手改往左跑。
4. 按 `←`：光标回到「停止」，野手应该立刻站住。
5. 按 `←` 再按一次：光标挪到「右移」，野手改往右跑（左右都是环绕）。
6. 在三个按钮上分别按回车：都是起跳（见 BASE-04）；缓冲期间再按回车什么也不发生；
   `↑ ↓` 在只有一行的盘里什么都不做。
7. 攻方视角按 `← / →`，看光标在「撤回 / 停止 / 前进」之间挪，挪到哪个跑哪个。
8. 落地捡球时：光标落下野手朝球位跑，**到球位自动停住**，那一刻传球按钮立刻出现
   （不用等下一拍）；此时默认光标停在「不传」，按方向键只是挪光标、**不会发货**，
   要按回车才传。捡球跑位时按回车不会起跳、也不会报错。

**预期**

- 按钮是 `╭─╮` 框，光标那个高亮；同一行按钮并排，操作区固定 8 行（标题 1 行 + 按钮 3+1+3，`controls_height=8`），
  不超高、不折行。
- **方向键只用来选择选项**：它只把光标挪一格，`← →` 在同一行里挪、`↑ ↓` 换行
  （换回来仍停在那一行原来那个按钮上）。
- **环绕**：挪到行尾再按会回到行首，和 UNO / Ludo 的按钮行、和所有菜单一套语义；
  方向键永远不会替玩家换向、也不会替玩家停。
- **光标落下＝那个按钮生效**（不用回车）：追球是**持续状态**，选「右移」就一直往右跑，
  直到光标挪回「停止」；跑垒三个按钮同理。野手可能追不上球（球比人快），
  但不会在某一格被系统冻住。
- **不可撤销的动作仍然要回车**：传垒、投球、打击；回车起跳是限时动作（见 BASE-04）。
  这一点 2026-10-14 经用户确认，2026-10-21 把接球动作换成了回车起跳。
- `h` / `l` 与 `←` / `→` 完全等价，都只是挪光标。

**证据**：守方飞行一行按钮、攻方跑垒按钮、传球按钮各一张截图。


## BASE-10 转传双杀与高飞牺牲打（触垒进垒）

**前置条件**：一垒有人时击出滚地球（BASE-05 的捡球步骤），或三垒有人时击出高飞球。

**步骤**

1. 一垒有人，打者击出滚地球，守方跑到球位后按回车传「二垒」。
2. 球在二垒判出局后**不要收手**，看棋盘下方的按钮换成了什么。
3. 把光标落在换出来的那个垒上按回车，看第二传的飞行进度条与播报。
4. 三垒有人，打者击出高飞球并被野手接杀（接杀播报出现后）。
5. 这时看攻方操作区（应当是「撤回 / 停止 / 前进」，光标回到「停止」），然后把光标挪到「前进」。
6. 等传球进度条走完，看播报是安全得分还是触杀；再重来一次，这回保持在「停止」。

**预期**

- 在垒上判出局后，只要还有人被迫在跑，球就停在那个垒上：棋盘中间那一槽显示 `转传`、
  外野线上球停在那个垒位，按钮只剩**还有人被迫在跑**的那几个垒，
  距离是从球所在的垒算起的（不是再跑一遍外野）。
- 第二传有完整的传球进度条（和外野线、第一传一样长）；球到垒判出局时播报 `封杀 …`，
  第二个人也被传杀后追加 `双杀`（同一拍两个出局，出局数 +2）。
- 高飞被接杀后，没提前离垒的人还能赌一个垒：攻方操作区还是那三个按钮、
  「阶段」显示 `触垒`（守方视角是 `等触垒`，守方这时没有按键可发）。
- 这是**等攻方决定**的阶段：不按就一直等（和投球 / 打击一样，没有倒计时）；
  「停止」或「撤回」＝都回原来的垒、这一拍结束。
- 选「前进」后马上开一条传球进度条，目标是**他会去的那个垒**（三垒有人＝本垒）；
  人先到＝安全（跑回来就是牺牲打得一分），球先到＝`触杀` 出局。
- 这一拍若出现第三出局且是封杀 / 打者出局，同一拍跑回来的分**不加分**。

**证据**：转传窗口（按钮只剩被迫垒位）、第二传进度条与 `双杀` 播报、触垒窗口、
牺牲打得分与触杀各一张截图。

## BASE-11 三条固定行（画面不变形）

**步骤**

1. 进比赛后盯棋盘底部：应该是三条带前缀的行（投打、外野、传球），
   每行两端都有一根 `│` 标出轨道边界。
2. 依次经历 出牌 → 倒数 → 投球段 → 挥棒段 → 击出飞行 → 捡球 → 传球，每一步都看这三行。
3. 在投球段观察球是不是**从右往左**飞；打完一球后看投打行前缀后面的符号变成什么，再看下一球开投时它变回什么。
4. 传球时看传球行（第 1 格人、球从最左走到最右、右竖线右边是目标垒名）；不传球时看它是不是只剩格点。
5. 把窗口缩到最小（88×32）看三条行有没有被挤掉或折行；再拉宽窗口，看三行是不是始终一样长、都铺到最右边。
6. 两边交牌后盯两条竖线：**左竖线在三条行上同一列**（投打行左竖线左边还有本垒结果符号，
   符号和竖线之间要空一格，不许贴上去），
   **右竖线也在三条行上同一列**；投打行右竖线右边是倒数 `3`→`2`→`1`（贴棋盘右边缘），
   外野行右竖线右边是本垒打墙。
7. 盯四个垒包连成的方框**里面**：中间有四行实时内容，位置永远不动——
   第一行这一拍的判定（`安全 SAFE` / `接杀 FLY OUT` / `封杀 FORCE OUT` /
   `触杀 TAG OUT` / `全垒打 HOME RUN` / `三振 STRIKEOUT` / `保送 WALK` / `双杀 DOUBLE PLAY`）、
   第二行倒数、第三行交牌灯（出牌阶段 `投 ●  打 ○`）或球的方位（`飞向` / `落点`）、
   第四行当前动作（投球 / 挥棒 / 追球 / 跑垒 / 捡球 / 传球 / 触垒）。哪一槽没内容就应当是空白，
   **别的内容不许挪过来**，方框的行数与宽度也不许变；
   **安全上垒（或任何判定）之后进入下一球的出牌阶段，两盏灯必须照旧在第三行**，
   上一拍的判定仍在第一行，两者同时可见、互不顶替；
   球被打出后垒名旁边出现传球距离：左边的三垒/本垒距离写在名字右边，右边的二垒/一垒
   距离写在名字左边，**四个垒名有没有距离都在同一列，不许左右挪**；
   **槽里是中文时（判定／动作／传给哪个垒）方框那几行也必须和别的行一样宽**——
   汉字占两列，落位时要连占两格，不许把右竖线顶出去。

**预期**

  三条行**任何阶段都在、长度一样**（每一档窗口宽度都刚好铺满整块棋盘），
  顺序是「投打 / 外野 / 传球」，**两条竖线在三行上同列**：
  左竖线左边是行标识（投打行还多一个本垒结果符号 + 一格空隙），右竖线右边是留白——
  外野行那格画**本垒打墙**（铺到棋盘右边缘），投打行那格写**倒数**（右对齐、同样贴右边缘），
  传球行留空。三行共用同一套 12 个格点、格点列位严格对齐；阶段变化只让行里的球和人移动，
  行本身不会出现、消失或变形。
- 投打行第 1 格＝本垒结果符号：空心圆（还没结果）→ 叉（挥空）/ ↗（高飞、全垒打）/ →（平飞）/ ↘（滚地），
  并且**保持到下一球开投**才复位；投手**站在右竖线外面**（竖线外隔一格，和倒数同在右侧留白里，
  倒数仍贴棋盘右边缘），任何阶段都在；球道的 12 格里没有他，球从第 12 格起飞。
- 传球行不传球时**只有格点**（不摆人、不写垒名），传球时第 1 格才是守方野手、
  球从最左一格走到最右一格，目标垒名在这行右竖线右边。
- 88×32 下棋盘全部可见、不出现滚动条；内野正方形因为多了三条固定行比原来矮。

**证据**：三个阶段的棋盘截图（含投打段与传球段）。

## BASE-12 提前放出的下一步（画面不变形）

**步骤**

1. 投打两段动画期间看操作区：标题、菜单内容、游标的颜色。
2. 那时候按回车、左右上下挪游标，看有没有动作发出去；动画结束后再看同一个菜单。
3. 打一个滚地球，让野手捡球后传球；传球进度条跑的时候看操作区。
4. 顺手把每个二级菜单翻一遍，确认它只写取值名字。

**预期**

- 动画期间操作区**先摆出下一刻的菜单**（守方的跑位盘、下一次传垒），
  一级盘没有标题（标题只属于二级菜单），游标**颜色变淡**（表示还按不动）——挪得动、回车不发货。
- **任何阶段操作区都有按钮，不允许空白或整块灭掉**（用户 2026-10-15 定）：
  走查这四个窗口，每个都要有按钮——
  ① 守方交完牌等对手交牌；② 两边交完、倒数 3→2→1 期间（这两个窗口里守方手上是
  「投球」键：暗着、按不动，倒数数完那一刻亮起，按下才真的投出去）；
  ③ 高飞被接杀后的触垒窗口（守方没动作 → 摆下一球的投球表单；攻方是真能按的三个跑垒键）；
  ④ 打者交完牌等开投（「击球」键在，暗的、按不动、无提示，开投那一刻亮起来）。
  例外只有打者那颗「击球」键：它按不动时不算预告、也不给任何提示。
- 动画一结束、阶段一到，**同一个菜单原地生效**，游标还停在你摆好的位置（不用重新找）。
- 传球途中守方能看到能传给哪些垒；球一到垒，同一排按钮立刻可以按。
- 预告里**不会出现**接球与攻方跑垒按钮：球有没有被打中要到揭晓那一帧才看得出来
  （保密契约，见 BASE-06）；守方在投球段只预告跑位盘（左移 / 停止 / 右移），
  接球三键在球真被击出那一刻才加入。
- 交完牌之后的等待不算"没动作"：守方的投球表单、打者的「击球」键都**原位留着**，
  不会切走、不会消失（切走就挡着你准备下一步）。
- 二级菜单里**一个效果数字都没有**（没有 `进场 61%`、没有 `接触 +8%` 这类东西）——
  只有取值名字 + 「返回」。

**证据**：动画期间的准备态、传球途中守方预告、二级菜单三种各一张截图。

## BASE-13 局数设置与逐局比分

**前置条件**：一个客户端会话（对机器人即可）。

**步骤**

1. 进入棒球的游戏详情，看设置里有没有「局数」一项（1–9 局，默认 3 局）；改成 2 局后创建房间。
2. 看等候室左侧「房间」面板：应该多一行 `局数    2 局`；添加机器人，开始比赛。
3. 开局那一行写 `开赛 bob 先攻 alice 后攻 共2局`；看右栏局面页的局数行：`局数 1/2 ▲`。
4. 翻到右栏「比分」页，打一会儿，看逐局得分：`局 1 2 合计`，上半局打完后客队那一格有数字、
   主队那一格从 `-` 变成 `0`。
5. 打满 2 局结算；再各用 1 局和 9 局（至少看一次 1 局：上半结束主队领先时下半局不打）重复，
   比较奖励。

**预期**

- 「局数」设置和 UNO 的设置同一个位置、同一种操作；创建后局数不能再改。
- 局数在整场比赛里一路生效：开局播报、局面页 `当前局/总局数`、比分页的列数、「末局」的判定
  （标准终局规则不变：末局上半结束主队领先则不打下半、末局下半反超立即结束、打平＝平局）。
- 1 局的比赛从开始到结算都正常；9 局时比分页数字仍然对齐、名字过长被截断但数字完整。
- **奖励按「局数 ÷ 3」缩放**：1 局约三分之一、3 局不变、9 局三倍（经验、金币、段位分同比例）。
- 终局时比分页里不必再打的下半局写 `X`，没打到的写 `-`。

**证据**：游戏详情里的局数设置、等候室房间面板、比分页（1 局与 9 局各一张）、两种局数的结算结论。

## BASE-14 记录栏：一次一行、可以回看、写法不啰嗦

**前置条件**：一个客户端会话（对机器人即可），终端 88×32 与更宽的窗口各看一次。

**步骤**

1. 打一场，盯着窗口最上方那一栏（记录栏，只有一行）：每一球、每次击出、每次传球之后看它写了什么。
2. 重点看这几种时刻：一球好球 / 坏球 / 挥空 / 界外；击中之后球落地或被接杀；封杀、触杀、双杀；
   得分；三出局换攻守；比赛结束与结算。
3. 打到有十几条记录后，用 `shift+↑` 把焦点移到记录栏，按 `↑` 往回翻：每按一次应该正好退一条；
   再按 `↓` 往回翻到最新一条。
4. 停在回看状态时，让对局继续产生新记录（或等机器人出一球）：看栏上的内容会不会被拽走。
5. 回看到一半，把焦点移回棋盘（`shift+↓`）。
6. 打开「记录」窗口，对照同一时刻有哪些行；窗口开着的时候继续打，看新记录会不会接着往下写。

**预期**

- 栏上默认停在**最新一条**，一条一行；太长的尾部用 `…` 收住（88 列下也一样），完整的在记录窗口里。
- 记录栏聚焦后 `↑` / `↓` 每次正好翻一条，下边框写 `第几条/共几条`（如 `12/30`）；
  回看时新记录进来，栏上的内容**不动**，只有总数变；翻回最新一条或焦点离开记录栏，
  就回到最新一条、下边框的数字消失。
- **整个记录里没有中文标点**（`，；：。！？（）`），一件事一行、词组之间只有空格；
  同一件事只说一次——出局在出局那一行，收尾行只列还没说过的结果。
- 每一拍栏上留下的是**这一拍的结论**：
  - 一球：`挥空 0-1 时机提前 预判错误`（结果、计数或打席结局、时机事实在同一行；计数是 `坏球-好球`）；
  - 得分：`三垒跑者得分 bob 4-2 alice`（带着最新比分，客队在前）；
  - 出局：`封杀 二垒 一垒跑者 2出局`（带着出局数）；
  - 三出局：最后一个出局那一行之后紧跟 `攻守交换 第2局上半 bob 进攻`；
  - 结算：`获胜 3-1 经验+150 金币+30`（自己的比分在前）。
- 很长的一行只在词组之间换行，一个词组不会被劈开。
- 记录窗口开着的时候新记录接着往下写，打开时仍是最近 16 条。

**证据**：上述各种时刻栏上那一行的截图（至少：一球结果、得分、三出局、结算各一张），
一张回看状态（下边框有 `n/total`）的截图，一张记录窗口。
